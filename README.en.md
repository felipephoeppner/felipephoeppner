## Projects and studies

### [ZombiePlus — Test automation with Playwright](https://github.com/felipephoeppner/Playwright-zombiePlus)

Learning project developed through the **Playwright Zombie Course**, with automated tests for the ZombiePlus application using **Playwright, JavaScript, Faker, and PostgreSQL**.

The implementation includes:

- Administrator login, invalid credentials, and required-field tests.
- Waiting-list lead registration, duplicate email checks, and form validation.
- Movie creation, deletion, and search, with required-field and duplicate checks.
- Organization into specs, reusable actions, fixtures, and test data.
- HTTP requests for authentication and data setup, plus PostgreSQL queries for test environment cleanup.
- HTML and JSON reports, screenshots on failure, and traces according to execution settings.
- An initial GitHub Actions workflow with a working CI pipeline.

**Goal:** practice UI automation, reusable actions, and data management for end-to-end scenarios.

**Status:** course completed, with further study and implementation of data isolation planned.
